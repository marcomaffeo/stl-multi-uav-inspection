## MATLAB folder contents

Here is a list with a brief description of the folder content:

* The **casadi**, **casadi-osx**, **casadi-windows** folders contain the CasADi library for Linux, macOS, and Windows distributions, respectively. CasADi is a symbolic framework for algorithmic /differentiation and optimal control.
* The **cvx** and **cvx-windows** folders contain the CVX framework for Linux and Windows distributions, respectively. CVX is a MATLAB-based modeling system for convex optimization.
* The **MPT3** folder contains the MATLAB script for installing the `Multi-Parametric Toolbox 3 + toolboxes`.
* The **STL_examples** folder contains the MATLAB scripts used to formulate an example of a motion planning problem leveraging Signal Temporal Logic Specifications.
